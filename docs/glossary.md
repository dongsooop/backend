# Glossary

프로젝트 전반에서 여러 도메인이 함께 사용하는 **공통 용어**를 관리합니다.

도메인 고유 용어의 원본은 각 `docs/domains/<domain>.md`의 `Terminology` 섹션입니다.

## 작성 원칙

- 같은 개념에는 하나의 용어만 사용합니다.
- 프로젝트 전반에서 반복되는 개념만 이 문서에 정의합니다.
- 특정 도메인이 소유한 개념은 해당 도메인 문서에서 정의합니다.
- 다른 도메인이 특정 도메인의 개념을 사용할 때는 소유 도메인의 용어를 그대로 사용합니다.
- 다른 문서의 용어 정의를 복사하지 않고 원본 문서를 참조합니다.
- 코드의 타입명, 필드명, API 용어와 문서 용어가 다르면 혼동이 생기므로 가능한 한 동일한 표현을 사용합니다.
- 새로운 공통 용어를 추가하기 전에 기존 용어 또는 도메인 용어와 의미가 겹치는지 확인합니다.

## Common Terms

### Domain Document

`docs/domains/<domain>.md`에 위치하며, 해당 도메인의 책임, 용어, 주요 기술적 결정을 설명하는 문서를 의미합니다.

PR 설명보다 장기적으로 유지해야 하는 설계 맥락을 상세하게 기록합니다.

### Owner

특정 용어, 정책 또는 결정을 최종적으로 정의하고 관리하는 도메인 또는 문서를 의미합니다.

같은 정의를 여러 문서가 동시에 소유하지 않습니다.

### Source of Truth

특정 용어, 정책 또는 결정의 원본이 되는 단일 문서를 의미합니다.

다른 문서에서는 내용을 다시 정의하지 않고 원본을 참조합니다.
